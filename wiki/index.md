# index — каталог страниц вики

Каталог всех страниц вики «Sudoku Gym»: ссылка + одна строка сути. Читать первым при ответе на любой вопрос, затем открывать нужные страницы. Обновляется при каждом ingest и любом изменении состава или сути страниц.
Последнее обновление: 2026-10-31. Фаза: ТРЕНИРОВКА — по умолчанию: разбор источников о скоростном решении, анализ партий и упражнений из `data/sudoku.db`, тренировочные эксперименты (что меняем в тренировке → метрики из БД). Новые фичи и правки кода тренажёра — только по явному запросу владельца; идеи → `ideas-parking.md`..

## Схема и навигация

- Схема — блок `claude-setup:wiki` в `CLAUDE.md` в корне проекта: слои, карта, уровни достоверности, операции Ingest/Query/Lint, профиль домена.
- [BACKLOG.md](BACKLOG.md) — открытые вопросы, UNKNOWN и CONFLICTING, у каждого — «зачем».
- [log.md](log.md) — хронологический журнал операций (init/ingest/query/lint/decision/experiment/schema).
- [ideas-parking.md](ideas-parking.md) — идеи одной строкой со статусами parked / rejected / accepted.

## Вне вики (читать, не переписывать)

- [../progress.md](../progress.md) — профиль ученика, цели, журнал сессий; ведёт скилл `sudoku-speed-coach`.
- [../theory/](../theory/) — теория техник, которую показывает тренажёр (`#/theory`): одиночки, пары, pointing/claiming, X-Wing, Y-Wing, сканирование, привычки скорости, нотация Снайдера.
- [../docs/superpowers/](../docs/superpowers/) — спека и план Sudoku Gym (код).
- `../data/sudoku.db` — партии, упражнения, паузы; источник MEASURED, только `mode=ro`.
