# Sudoku Gym

[English](README.md) · **Русский**

Локальный тренажёр скоростного судоку на русском и английском. Вдохновлён [Monkeytype](https://monkeytype.com) (темы, шрифты, минимализм) и [lichess](https://lichess.org) (дзен-режим, задачи-упражнения).

- **Игра**: 20 000 задач с фильтром по технике, режимы original и hardcore как на usdoku, свои сетки (можно вставить с usdoku), задача дня.
- **Разбор каждой партии**: обзор пауз, пошаговая подсказка, когда застрял (техника → где → паттерн → ход), доска анализа и решение солвером с любого момента (`#/solve/{id}`).
- **Упражнения**: «найди ход» для 10 техник с объяснениями и рейтинг как на lichess — относительно твоей же нормы по каждой технике.
- **Теория**: страница на технику с диаграммами, разобранным примером и прогрессом в упражнениях.
- **Статистика**: календарь активности, серия дней и рекорды. Оформление и избранное выгружаются в JSON.
- **Наставник**: Claude Code ведёт тренировки через скилл `sudoku-speed-coach` (`.claude/skills/`) и читает прогресс прямо из базы.

## Запуск

```bash
./gym start    # собрать Docker-контейнер, дождаться сервера, открыть http://127.0.0.1:8765
```

Первый запуск скачивает банк задач ([grantm/sudoku-exchange-puzzle-bank](https://github.com/grantm/sudoku-exchange-puzzle-bank), public domain) и строит упражнения — пара минут. Дальше контейнер поднимается вместе с Docker, хватает `./gym open`. Прогресс хранится в `data/sudoku.db` (не в git), каждый запуск делает копию в `data/backups/`.

Без Docker: `./gym dev` запускает из рабочей папки на Python 3.14+. Если такого Python нет, а есть [uv](https://docs.astral.sh/uv/), он поставит Python через uv.

**Windows**: склонируй или скачай репозиторий и дважды щёлкни `gym.cmd`. Если Python 3.14+ нет, он предложит поставить его через winget. Чёрное окно не закрывай, пока играешь.

| Команда | Что делает |
|---|---|
| `./gym start` · `stop` · `restart` | запустить, остановить, пересобрать контейнер (прогресс в `data/` остаётся) |
| `./gym open` · `status` · `logs [N]` | открыть браузер, проверить сервер, смотреть логи |
| `./gym dev` | запуск без Docker (`PORT=8766 ./gym dev` — другой порт) |
| `./gym backup` | копия `data/sudoku.db` в `data/backups/`, хранятся 20 последних |

Переменные: `NO_OPEN=1` — не открывать браузер, `BACKUP_DIR` и `KEEP` — куда и сколько бэкапов хранить.

Не работают цифры в Firefox? Расширения вроде Vimium перехватывают клавиши: добавь `http://127.0.0.1:8765/*` в их исключения. `http://127.0.0.1:8765/?debug` показывает, куда уходит каждое нажатие.

## Разработка

Python 3.14+, только стандартная библиотека; интерфейс — vanilla JS в `web/`. Инструменты (ruff, pre-commit) запускаются через `uvx`, ставить ничего не нужно.

```bash
./gym setup          # один раз: git-хуки (ruff, юнит-тесты, без AI-трейлеров в коммитах)
./gym test           # юнит-тесты, затем e2e, если найдены node и playwright-core
./gym test unit      # только юнит; ./gym test e2e — только e2e (BROWSER=firefox)
./gym check          # все хуки по всем файлам
python3.14 tools/regrade.py   # пересчитать tech_grade после правки техник в ядре
```

| Модуль | Роль |
|---|---|
| `sudoku_core.py` | кандидаты, шаги с названием техники, солвер, сложность 1–5 |
| `db.py` | схема SQLite, подключение и миграции |
| `analysis.py` | метрики партии, обзор пауз, статистика, календарь и серии, задача дня |
| `drills.py` | генерация упражнений, адаптивный выбор, открытие техник, объяснения |
| `hints.py` | ошибки на доске и в заметках, 4 уровня подсказки, линия решения |
| `rating.py` | рейтинг упражнений: нормы по техникам, Elo по истории попыток |
| `server.py` | HTTP API и статика |
| `theory/*.md` | статьи теории; блоки ```` ```sudoku ```` рисуются доской (формат — в `web/js/diagram.js`, проверяет `tests/test_theory.py`) |
