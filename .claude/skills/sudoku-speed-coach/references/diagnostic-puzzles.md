# Диагностические головоломки

Все сетки сгенерированы и проверены солвером: решение единственное, уровень определён по техникам, необходимым для решения.

- **L1** — решается только одиночками (naked + hidden singles).
- **L2** — требует locked candidates (pointing / claiming).
- **L3** — требует голых или скрытых пар.

Давай ученику по одной сетке. Проверяй ответ **только** по строке «Решение». Решение ученику не показывай до конца попытки.
